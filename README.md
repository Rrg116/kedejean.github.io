# CV en ligne — Kede Jean François Regis

## Contenu
- `index.html` : page principale
- `style.css` : design responsive
- `script.js` : interactions légères

## Publication gratuite avec GitHub Pages
1. Crée un compte GitHub si nécessaire.
2. Crée un dépôt public nommé `kede-cv` (ou `kedejeanfrancois.github.io` si tu veux un lien personnalisé).
3. Envoie `index.html`, `style.css` et `script.js` dans le dépôt.
4. Dans **Settings → Pages**, active GitHub Pages depuis la branche `main`.
5. GitHub affichera l'adresse publique de ton CV.

Le site est déjà responsive pour téléphone, tablette et ordinateur.
